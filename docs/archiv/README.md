## Warum archiviert?

Die Dateien lagen im Repo-Root und tauchten dadurch bei praktisch jeder
Codesuche als Treffer auf. Zusammen rund 130 KB — sie wurden regelmaessig in den
Kontext von Werkzeugen und Assistenten geladen, ohne inhaltlich beizutragen.
Das Verschieben aendert keinen Code und keine Compliance-Aussage.
